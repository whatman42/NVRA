# NVRA V7 Deep Audit — 2026-08-28

## Scope
Baseline: `NVRA-UNIFIED-BROKER-MODES-V6.zip`. Audit covers Python source, package imports, workflows, requirements, configuration, packaging, execution boundaries, and V7 additions.

## Findings and remediation
- **Circular import:** `god.execution.protocols -> god.agent -> god.agent.core -> god.execution.protocols` was found during V7 test collection. Fixed by making agent core exports lazy.
- **Generated artifacts:** `.pyc`, `__pycache__`, `.pytest_cache` are release-excluded.
- **Temporary source artifact:** `god/broker/__init__.py.tmp` removed.
- **Windows workflow duplication:** redundant canonical Windows build workflows removed; `windows-build.yml` is the canonical build path.
- **Dependency contract:** `requirements-ml-full.txt` is an alias to the canonical `requirements.txt`; runtime/build/ML dependencies are declared in one place.
- **Packaging:** PyInstaller spec uses package discovery for `god`, `crypto`, and `nvra_unified` to reduce hidden-import drift.
- **IDX rules:** configurable lot/tick/session/ARA-ARB validation added. Regulatory values remain configurable and are not represented as legal advice.
- **Accounting:** commission, exchange fee and sell-tax inputs are configuration-driven with effective-date/source metadata.
- **Recovery:** durable order journal, idempotency key, UNKNOWN-state semantics and fail-closed reconciliation added.
- **Operational:** DEMO certification runbook, severity contract and extreme-market scenarios added.
