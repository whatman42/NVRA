## Important fixes

1. Added `MLModelGovernor`.
   - Hardware profile supplies the model-slot ceiling.
   - Governor state further reduces the ceiling under pressure.
   - Model quality uses test accuracy first, then validation accuracy.
   - Runtime latency/error EWMA can demote slow or unstable models.
   - ULTRA_LITE uses one model; high-end EXTREME can use up to four strong
     optional backends.
   - Fallback remains a safety net, not a normal ensemble peer when real
     models are available.

2. Integrated model selection into `EnsembleEngine`.
   - Loaded model catalog is separate from active model set.
   - Inference latency and failures are observed.
   - Selection is auditable through `MLSelection`.

3. Improved Windows hardware/telemetry.
   - Physical RAM detection through Windows API.
   - Windows power status through Windows API.
   - CPU/RAM/process/battery/temperature telemetry through `psutil` where
     supported.

4. Hardened LIVE production gates.
   - Withdrawal `UNKNOWN` is no longer accepted as safe.
   - LIVE requires real connectivity, permissions and measured time-sync probes.
   - Missing probes can still be tolerated for software-only validation but
     can never produce LIVE GO.

5. Upgraded GUI.
   - Informative dashboard for mode, safety, governor, hardware score,
     resources, ML active/loaded models, market freshness, equity, drawdown,
     daily loss and order state.
   - GUI remains observational and cannot bypass RiskEngine/ProductionGate.

6. Added Windows GitHub Actions build workflow.
   - Runs Ruff, mypy and pytest.
   - Installs GUI + full ML + Windows secure credentials + PyInstaller.
   - Builds one-folder Windows x64 EXE.
   - Runs packaged `--smoke`.
   - Produces `CRYPTO-Windows-x64.zip` and SHA-256 artifact.

## LIVE boundary

This package is **live-capable but not live-certified**. No honest software
audit can certify real-money trading without exercising the actual exchange
account, permissions, time synchronization, order round-trip and reconciliation.

The application remains PAPER by default. LIVE must pass the existing
ProductionGate and a real micro-capital canary before production GO.
